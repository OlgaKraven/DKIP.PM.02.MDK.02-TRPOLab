    Примерные вопросы для заета с оценкой по дисциплине «Технологии разработки программного обеспечения»

    Структура оценивания

    • Вопрос 1-го типа — 20 баллов
    • Вопрос 2-го типа — 20 баллов
    • Вопрос 3-го типа — 60 баллов

    Задание 1 (вопросы 1-го типа, 20 баллов)

    Ответить на теоретические вопросы, дать определения, классификации, перечисления.

    1. Классификация программных продуктов.
    2. Классификация инструментария технологии программирования.
    3. CASE-технология создания информационных систем.
    4. Понятия программного модуля, программного продукта, программного средства.
    5. Жизненный цикл разработки программного обеспечения.
    6. Процессы жизненного цикла ПО.
    7. Модели разработки ПО: спиральная, каскадная.
    8. Понятия изобретения, полезной модели, промышленного образца.
    9. Структура программного обеспечения.
    10. Проектирование и дизайн интерфейсов.
    11. Модульное программирование.
    12. Структурное программирование.
    13. Объектно-ориентированное программирование.
    14. Инструменты разработки программных средств.
    15. Организация работ при коллективной разработке программных продуктов.
    16. Дайте определение UML.
    17. Сколько существует видов диаграмм в UML и какие.
    18. Диаграмма вариантов использования.
    19. Диаграмма классов.
    20. Диаграмма объектов.
    21. Диаграмма компонентов.
    22. Диаграмма развертывания.
    23. Диаграмма последовательности.
    24. Диаграмма коммуникации.
    25. Диаграмма кооперации.
    26. Диаграмма потока данных.
    27. Диаграмма деятельности.
    28. Диаграмма состояний.
    29. В чём разница между диаграммами вариантов использования и последовательности?
    30. В чём разница между диаграммами классов и объектов?
    31. В чём разница между диаграммами компонентов и развертывания?
    32. В чём разница между диаграммами потока данных и деятельности?
    33. В чём разница между диаграммами состояний и деятельности?

    Задание 2 (вопросы 2-го типа, 20 баллов)

    Развёрнутые теоретические вопросы с пояснениями и примерами.

    1. Основные принципы процесса разработки программного обеспечения.
    2. Основные подходы к интегрированию программных модулей.
    3. Основные методы и средства эффективной разработки.
    4. Классификация программных продуктов.
    5. Классификация инструментария технологии программирования.
    6. CASE-технология создания информационных систем.
    7. Жизненный цикл разработки ПО и процессы жизненного цикла.
    8. Модели разработки ПО: спиральная и каскадная.
    9. Объясните разницу между диаграммой вариантов использования и диаграммой последовательности, приведите примеры и дайте определения.
    10. Опишите преимущества и недостатки использования UML для моделирования систем, дайте определения диаграмм.
    11. Приведите ситуацию, когда использование диаграммы классов может привести к путанице в проекте, дайте определения диаграмм.
    12. Объясните, как диаграмма компонентов помогает в планировании развертывания системы, дайте определения диаграмм.
    13. Приведите пример, когда диаграмма развертывания полезна при оптимизации производительности системы, дайте определения диаграмм.
    14. Опишите ситуацию, когда диаграмма последовательности информативнее диаграммы коммуникации, дайте определения диаграмм.
    15. Объясните, как диаграмма кооперации помогает понять взаимодействие объектов, дайте определения диаграмм.
    16. Приведите пример, когда диаграмма потока данных предпочтительнее диаграммы деятельности, дайте определения диаграмм.
    17. Объясните, как диаграмма состояний помогает понять поведение объекта во времени, дайте определения диаграмм.
    18. Опишите ситуацию, когда использование IDEF0 эффективнее, чем DFD, дайте определения диаграмм.
    19. Объясните, как IDEF3 помогает моделировать процессы с высокой точностью и детализацией, дайте определения диаграмм.
    20. Приведите ситуацию, когда IDEF3 предпочтительнее IDEF0, дайте определения диаграмм.
    21. Объясните, как IDEF3 применяется для процессов с временными ограничениями и параллельностью действий.
    22. Приведите пример, когда IDEF3 предпочтительнее DFD.
    23. Объясните, как IDEF3 позволяет моделировать обратные связи и циклические зависимости.
    24. Приведите ситуацию, когда IDEF3 предпочтительнее IDEF0.
    25. Объясните использование IDEF3 для процессов с временными ограничениями и параллельностью.
    26. Приведите ситуацию, когда IDEF3 предпочтительнее DFD.
    27. Объясните моделирование циклических зависимостей в IDEF3.
    28. Приведите ситуацию, когда IDEF3 предпочтительнее IDEF0.
    29. Основные принципы процесса разработки программного обеспечения.
    30. Основные подходы к интегрированию программных модулей.
    31. Основные методы и средства эффективной разработки.
    32. Классификация программных продуктов.
    33. Классификация инструментария технологии программирования.

    Задание 3 (вопросы 3-го типа, 60 баллов)

    Практико-ориентированные задания, требующие анализа, проектирования и построения диаграмм.

    1. Анализ предметной области системы управления университетом.
    2. Анализ предметной области мобильного приложения управления личными финансами.
    3. Разработка технического задания для веб-приложения онлайн-курсов.
    4. Разработка технического задания для системы управления проектами IT-компании.
    5. Архитектура системы электронной коммерции.
    6. Архитектура мобильного приложения заказа такси.
    7. UML: диаграмма вариантов использования для системы управления библиотекой.
    8. UML: диаграмма вариантов использования для фитнес-приложения.
    9. UML: диаграмма классов для системы управления складом.
    10. UML: диаграмма классов для системы управления библиотекой.
    11. UML: диаграмма объектов для системы социальных медиа.
    12. UML: диаграмма объектов для системы онлайн-образования.
    13. UML: диаграмма компонентов для веб-приложения электронной коммерции.
    14. UML: диаграмма компонентов для системы управления персоналом.
    15. UML: диаграмма развертывания для многоуровневой СУБД.
    16. UML: диаграмма развертывания для распределенной системы мониторинга.
    17. UML: диаграмма последовательности регистрации пользователя в онлайн-банкинге.
    18. UML: диаграмма последовательности оформления заказа в интернет-магазине.
    19. UML: диаграмма коммуникации для распределенной системы серверов.
    20. UML: диаграмма коммуникации для системы обработки заказов.
    21. UML: диаграмма кооперации для интернет-магазина.
    22. UML: диаграмма кооперации для системы бронирования билетов.
    23. UML: диаграмма потока данных (общее задание).
    24. UML: диаграмма потока данных для обработки изображений.
    25. UML: диаграмма потока данных для системы управления заказами.
    26. UML: диаграмма деятельности для процесса оплаты заказа.
    27. UML: диаграмма деятельности для регистрации пользователя.
    28. UML: диаграмма состояний процесса авторизации пользователя.
    29. UML: диаграмма состояний обработки заказа.
    30. UML: диаграмма классов для системы управления базой данных.
    31. UML: диаграмма классов для СУБД (расширенная).
    32. UML: диаграмма классов для СУБД (администрирование и резервное копирование).
    33. UML: диаграмма классов для системы управления библиотекой.
