# **Описание дисциплины ТРПО**

* Дисциплина: **Технология разработки программного обеспечения**
* Длительность: **1 семестр**
* Количество лабораторных: **10 лабораторных работ**
* Баллы за лабораторные: **60 баллов**
* ИМ: **Зачет с оценкой**

> Внимание! </br>
> У групп с приставкой **прог** - есть **обязательный** курсовой проект с дополнительной формой контроля! 
---

## **Темы курса**
1. Основные понятия программного обеспечения и методов разработки
    - Виды и классификации ПО. Жизненные циклы
    - Методы и способы разработки программного обеспечения
2. Создание проектной и технической документации
    - Основные виды технической и проектной документации по разработке. ГОСТ 34.602-2020. ГОСТ 19.201-78.
3. Методы и способы моделирования с помощью UML 2.0
    - Унифицированный язык UML 2.0.
    - Основные методы моделирования. Разновидность диаграмм при разработке программного обеспечения
    - Сравнительный анализ с помощью диаграмм различного типа.
4. Методы и способы моделирования бизнес-процессов с помощью нотация IDEFX
    - Основные понятия бизнес-процессов. Способы и методы анализа бизнес-стратегии предприятия.
    - Нотации моделирования бизнес-процессов IDEFX
5. Оценка качества программных средств 
    - Цели, задачи и виды тестирования. Стандарты качества программной документации. Меры и метрики.
    - Анализ спецификаций. Верификация и аттестация программного обеспечения.
